# STAP Kenya – AI‑Powered Sustainable Tourism Platform

**STAP Kenya** is an AI‑powered sustainable tourism intelligence platform for East Africa.  
Features include: live congestion maps, AI‑generated itineraries, a community marketplace with M‑Pesa integration, eco‑scoring, offline‑first edge nodes, and interactive GPS maps for 30+ destinations across Kenya, Tanzania, and Zanzibar.

## 📌 Overview

STAP (Sustainable Tourism Analytics Platform) helps travellers, tour operators, and conservationists make smarter, more responsible decisions.  
Built entirely with HTML, CSS, and JavaScript (vanilla), it runs in any modern browser and uses local storage for authentication and state.

## ✨ Key features

- 🤖 **AI itinerary generator** – personalised trips based on 7 preference categories (wildlife, cultural, adventure, beach, birding, historical, hiking)  
- 📊 **Live congestion monitoring** – real‑time capacity for 30+ gates with diversion simulation and LSTM‑based forecasts  
- 🗺️ **Interactive destination maps** – Leaflet maps with precise GPS coordinates for every site  
- 🛒 **Community marketplace** – M‑Pesa payment simulation, booking tracking, conservation credits  
- 🌿 **Sustainability dashboard** – eco‑score, carbon, water, waste, and biodiversity metrics  
- 📡 **Offline‑first architecture** – cached recommendations, edge nodes, background sync  
- 🔐 **User authentication** – login/signup with local storage persistence
